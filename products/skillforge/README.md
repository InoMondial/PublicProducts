# SkillForge — Skill Factory

**SkillForge is a factory for designing, building, testing, validating, packaging and governing reusable Skills.** The core contains 19 governance Skills (G0–G18), including security, lifecycle, testing, versioning, traceability, coordination and conversation-output controls.

## Releases
- **Current public source:** [v3.0.4](v3.0.4/) (packaging revision `3.0.4-public.1`)
- **Source-available license:** [LICENSE](v3.0.4/LICENSE). Personal, educational and non-commercial research use is permitted under its terms; commercial/organizational use needs separate written permission.
- **Setup:** [First-run guidance](v3.0.4/setup/CHATGPT_FIRST_RUN.md); external connections require explicit host authorization.
- **GitHub Release:** `skillforge-v3.0.4-public.1` after successful privacy and integrity gates.

The public product has no private account IDs, passwords, secrets, or live configuration values. It never automatically connects apps, writes public feedback or installs native ChatGPT skills simply because its sources are available.
