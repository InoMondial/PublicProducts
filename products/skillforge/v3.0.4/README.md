# SkillForge 3.0.4 - Public Source Edition

SkillForge is a factory for creating governed Skills. This edition contains 19 governance Skills (G0-G18), with no user-specific bindings or private history.

Edition: 3.0.4-public.1 (core 3.0.4). This is a distinct public source variant, not a copied private release ZIP.

## Use
Read LICENSE, NOTICE, THIRD_PARTY_NOTICES, TRADEMARKS, RIGHTS_PROFILE.yaml before installation. The source-available license reserves commercial/organizational uses for separate written permission.

See setup/CHATGPT_FIRST_RUN.md for guided setup. Downloading this source does not install Skills, connect apps or grant access to other services. Keep real service IDs and credentials in host-authorized private configuration outside this distribution. Feedback and telemetry remain OFF by default.

The 19 Skills are in skills/. A downloadable public ZIP is built from this source only after validation.
