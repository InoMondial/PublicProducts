# Public-source distribution boundary

The public SkillForge 3.0.4 source edition must not contain secrets, owner-specific service data, live host configuration, Handoff history or private evidence.

Validate every path, file, source module, archive member and package manifest. Missing or unreadable evidence fails closed. External service connections, optional public feedback and telemetry are OFF unless separately authorized and verified by the host. GitHub release assets must be generated from this approved public-source directory, with content digests and legal notices preserved. Public distribution does not guarantee native installation or erasure of previously published copies elsewhere.
