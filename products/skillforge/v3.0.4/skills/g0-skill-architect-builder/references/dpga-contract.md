# DPGA Contract — G0 Candidate

For every capability, record:
- capability_id / canonical_owner
- Build applicability
- Build application method
- Build evidence
- Runtime applicability
- Runtime surface/trigger
- Runtime contract/profile reference
- Runtime enforcement mechanism
- RT test/evidence
- N/A rationale / exception
- Validator verdict

Hard gates:
- DPGA_COMPLETE
- GOVERNANCE_PROPAGATION_COMPLETE

A Runtime declaration without a propagation mechanism is incomplete.
A propagation mechanism without behavioral evidence is incomplete when the behavior can reasonably be tested.
